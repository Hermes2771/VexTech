# VexTech

VexTech is a library / bundle of header files that you can import into your c++ vex projects!

As of 2025/10/22 it is untested, but contains all the code for vital game functions like odometry (tracks your robots position during the autonomous period), pure pursuit (allows your robot to track a path during autonomous) as well as controller and PID code.

Happy programming, vex teams!
